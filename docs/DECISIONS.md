# 技術上の決定

## 2026-10-10 — 既存構成へのテンプレート統合

採用。既存README、追跡中の`dist`、Node/webpack、通知用`.env.example`を維持し、不足する技術文書と作業ルールを補う。共有Codex規則は複製しない。テンプレートのためのサービス・CI・設定システムは追加しない。出典は [DEV_WORKFLOW](../DEV_WORKFLOW.md) に記載。

## 2026-10-10 — 保存実証を通常取得から分離

採用。ブラウザで認証付き取得した添付をFANBOX専用Pythonサービスへ分割転送し、通常ファイルとSQLiteへ保存する。既存Eagle経路・取得履歴を変えずに、永続化と重複受付を先に確かめるため。初期段階は64 MiBまでの手動1件保存とし、FIFO・遠隔設定・自動削除を含めない。保証と制約は [保存実証手順](FANBOX_FILE_PROOF.md) に集約する。

## ブラウザ起動のsandbox対応

提案・未適用。AppArmorの拒否に対応する専用実行パスの例外を検討している。OSのセキュリティ変更なので、起動承認だけを根拠に適用しない。承認対象と次の操作は [HANDOFF](HANDOFF.md) に置く。
